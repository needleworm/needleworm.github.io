
# Website content conventions

## 정적 페이지 생성

- 이 사이트는 빌드 시 본문이 포함된 HTML을 생성합니다. 브라우저에서 템플릿을 조립하지 않습니다.
- 원본 콘텐츠는 `content/sections/*.html`, 페이지 구성과 제목·설명은 `content/site.json`, 공통 레이아웃은 `content/layout.html`에서 관리합니다.
- `index.html`과 각 하위 폴더의 `index.html`은 생성 결과입니다. 원본을 수정한 후 `python scripts/build_site.py`를 실행하세요.
- `python scripts/build_site.py --check`로 생성 결과가 최신인지 확인하고, `python scripts/check_site.py`로 원문·카드 수·내부 경로·검색 메타데이터 보존 여부를 검사합니다. Python 표준 라이브러리만 사용합니다.
- GitHub Pages에는 생성된 파일을 함께 배포합니다. 별도 애플리케이션 서버는 필요하지 않습니다. GitHub Actions는 푸시와 PR에서 생성 결과와 콘텐츠를 검사합니다.
- 사이트맵은 기존 도서 예제 사이트 주소를 보존하면서 각 페이지 주소를 추가합니다. 실제 HTML 내용이 바뀐 페이지의 수정일만 갱신합니다.
- 홈 `/`와 `/books/`, `/media/`, `/news/`, `/courses/online/`, `/courses/offline/`, `/lectures/`, `/papers/`, `/patents/`, `/projects/`, `/activities/`, `/memberships/`, `/collections/`, `/contact/`는 모두 실제 `index.html` 파일이 있는 주소입니다. 이전 `/courses/` 주소도 물리적인 `index.html`을 유지하며 Online으로 연결합니다.
- 모든 카드와 본문은 처음부터 펼쳐집니다. Lectures의 기관별 목록과 바로가기·건수도 정적 HTML에 포함됩니다. JavaScript는 현재 읽는 기관 표시, 모바일 메뉴, 문의 폼, GitHub 통계 등의 상호작용만 처리합니다.
- 화면 디자인은 기존 `style.css`를 공통으로 사용합니다. 페이지 제목은 `group-header`·`group-title`·`group-desc`, 본문은 `section-group`을 유지하며, `page.css`에는 정적 페이지 전환에 필요한 보완만 둡니다. 홈 히어로와 기존 카드 크기·색상·간격을 별도로 덮어쓰지 않습니다.
- 콘텐츠 카드 목록은 화면 폭 1920px 이상에서 본문 최대 폭 1600px·4열로 표시합니다. 그보다 작은 화면의 기존 열 수와 홈·문의 페이지 배열은 유지합니다.
- 상단 메뉴는 `Lectures`와 `Courses`로 나눕니다. `Lectures`에는 기관별 출강 이력을, `Courses`에는 `Online / Offline` 교육과정을 표시합니다.
- 페이지의 맨 아래에서 모바일은 새로 시작한 위쪽 스와이프(90px 이상), 데스크톱은 추가 하향 스크롤로 다음 페이지로 이동합니다. 휠·트랙패드 입력은 300ms 넘게 멈춘 뒤 시작해야 하며, 페이지 끝에 도착한 동작의 관성만으로는 넘어가지 않습니다. 안내와 다음 페이지 링크는 본문 끝과 푸터 사이에 표시합니다. 실제 상단 메뉴 순서로 이어지고 Contact에서 끝나며, 메뉴·입력란·텍스트 선택·확대 상태에서는 이동하지 않습니다. 다음 페이지 링크는 직접 누를 수도 있습니다.
- 교육과정 원본은 `content/sections/courses-online.html`과 `courses-offline.html`에서 관리합니다. 온라인 영상·라이브 교육과 대면 교육을 실제 진행 방식으로 분류합니다. LG 인화원의 MVP·그룹스터디 과정도 사용자 확인에 따라 Online에 포함합니다.
- Online은 인프런 강좌(`inflearn.com` 또는 `inf.run` 링크)를 먼저 표시합니다. 인프런 강좌끼리와 나머지 교육과정끼리는 원본 순서를 유지하며, 빌드 시 자동 정렬합니다.
- Offline 과정은 Lectures에도 함께 표시하고, Lectures에서 출강일이 3개 이상인 항목은 Courses에도 표시합니다. 날짜가 부족한 기록의 사용자 확인 결과와 Online/Offline 구분은 `content/cross-listing.json`에서 관리합니다. 반복 출강의 진행 방식이 미확인 상태이면 빌드를 중단하므로 임의로 분류하지 않습니다.
- 교차 게재하는 카드의 제목·설명·이미지는 원본 한 곳에서만 관리합니다. `data-record-id`는 항목을 참조하는 고유값이며, Offline 원본의 `data-category`는 Lectures의 기관별 목록에도 사용됩니다. 목록 안의 중복과 반복 교차 게재는 생성기가 방지합니다. Offline은 전체 최근 날짜순, Lectures는 각 기관 분류 안에서 최근 날짜순으로 정렬합니다.
- 홈의 강의 통계는 교차 게재 전 원본 수로 계산해 중복 집계를 피하고, 강의 이력 바로가기에는 실제 목록에 표시되는 수를 사용합니다.
- 모바일 홈은 소개 다음에 전체 Books 목록을 바로 표시하고 Explore 바로가기를 숨깁니다. 책 목록은 `/books/`와 동일한 원본에서 생성하므로 제목·이미지·구매 링크를 따로 관리하지 않습니다. 모바일 홈의 다음 페이지는 이미 표시한 Books를 건너뛰고 Media로 이어지며, 데스크톱 홈은 Explore와 다음 Books 연결을 유지합니다.
- 사회공헌의 기부 내역은 `content/sections/social.html`에서 관리합니다. 금액이 공개되지 않은 항목은 `미공개`로 표시하고, 누적 후원은 개별 내역과 중복 합산하지 않습니다. 같은 기관·같은 달에 별도로 기록된 기부는 임의로 합치거나 삭제하지 않습니다.
- 기존 `/#books`, `/#education-section` 등의 외부 링크는 JavaScript가 새 페이지로 연결합니다. 새 링크에는 해시 대신 실제 페이지 주소를 사용하세요.
- `src/resource_forward`의 외부 사이트용 책·문의 조각은 별도로 보존합니다. 공통 콘텐츠를 변경하면 해당 조각의 동기화 여부도 확인하세요.

## 강의 이력

- 같은 연도에 여러 번 진행한 강의는 연도를 처음에만 적습니다: `2026.09.10. 09.24.`
- 연도가 달라지면 새 연도를 다시 적습니다: `2025.12.20. 2026.01.10.`
- 강의 카드 안의 날짜는 오래된 날짜부터 순서대로 적습니다.
- Lectures는 `기업 → 공공기관 → 교육기관 → 연구기관 → 컨퍼런스` 순서의 다섯 기관 분류가 한 문서에서 계속 이어집니다. 다른 분류를 읽기 위해 탭을 바꾸거나 목록을 다시 불러올 필요가 없습니다.
- 각 기관 분류 안의 강의 카드 목록은 가장 최근 진행일 기준 내림차순입니다. 여러 날짜가 있으면 가장 늦은 날짜를 기준으로 합니다.
- 월일을 알 수 없는 강의는 `2024년`처럼 연도만 적습니다. 같은 해의 정확한 날짜가 있는 강의 뒤, 이전 연도 강의 앞에 정렬하며 같은 연도끼리는 기존 순서를 유지합니다.
- `scripts/build_site.py`는 교차 게재를 마친 전체 강의 카드를 `#lecture-list.lecture-sections` 안의 다섯 `section.lecture-category`로 묶습니다. 각 분류의 제목·건수와 카드 그리드를 빌드 시 생성하므로 자바스크립트 없이도 전체 목록을 읽을 수 있습니다. 같은 날짜인 항목은 원래 순서를 유지합니다.
- 강의 카드의 `data-category`에는 `기업`, `공공기관`, `교육기관`, `연구기관`, `컨퍼런스` 중 하나를 적습니다. 학교·대학교·도서관은 `교육기관`입니다.
- 교육부·교육청·교육지원청과 교육청연수원·특수교육지원센터 등 교육행정 소속기관은 `공공기관`으로 분류합니다. 도서관·학교는 `교육기관`을 유지합니다.
- 국가공무원인재개발원·보건복지인재원 등 공공 인재개발기관은 `공공기관`, KIRD는 `연구기관`으로 분류합니다.
- 한국생산성본부·농협중앙회·신협중앙회·한국가스안전공사·한국공항공사·미래와소프트웨어재단·서울시 기계공업 협동조합·한국건설기술인협회는 `기업`으로 분류합니다.
- 진로체험센터·직업교육센터·여성발전센터·노인종합복지관은 `공공기관`으로 분류합니다.
- 학회·개인 모임은 `컨퍼런스`로 분류합니다. 별도로 확정한 협회·재단의 분류를 우선하며, 새 강의처의 분류가 모호하면 임의로 확정하지 않고 사용자에게 확인합니다.
- 목록 앞의 기관 바로가기는 `전체`와 다섯 분류의 건수를 표시하는 문서 내부 링크입니다. 해당 제목으로 이동하며 다른 분류의 카드를 숨기지 않습니다. 분류별 제목과 바로가기 건수는 원본 카드에서 자동 집계하고, 알 수 없는 `data-category` 값이 있으면 빌드를 중단합니다.
